# Changelog

All notable changes are recorded here. Account-specific live evidence is kept
outside the public repository.

## 1.0.0 — 2026-08-20

### Added

- Fourteen semantic MCP tools, including one-task authorization, typed audit,
  bounded learning, and inventory/page discovery.
- Short-lived `observe`, `copy-test`, and `production` authority modes with
  exact scopes, operation allowlists, TTL, revocation, and publication gates.
- Safe Standard-field routing that preserves unknown fields and rejects
  identity, routing, ordering, and control fields.
- T123 full/single/bounded-literal editing and bounded Zero property/clone
  adapters alongside the reproduced narrow transitions.
- Same-project reference-page copy/cleanup, known template recipes, and
  hover-only record-control revelation with no coordinate clicks.
- Practical v1 documentation, task-authority policy/schema, synthetic tests,
  and a public read-only fourteen-tool MCP smoke.

### Safety and evidence

- ChangeSets retain snapshots, optimistic hashes, idempotency, rereads, and
  rollback/restore boundaries; ambiguous writes fail closed.
- Editing and publication remain separate operations and approval gates.
- The public package contains no real account IDs, private fixtures, raw
  payloads, credentials, browser state, customer data, or private traces.
- Narrow live contracts remain privately lab-verified and do not imply
  universal Tilda coverage.

## 0.2.0-prealpha

- Added the typed Phase 2 MCP vertical slice, ChangeSet engine, narrow adapter
  contracts, publication controller, page lifecycle, and sanitized OSS package.
