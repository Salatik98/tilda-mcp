# Roadmap

## Phase 1 — evidence-first primitives

- [x] CDP target discovery, inventory normalization, hashing, and status.
- [x] Fail-closed target/source-corpus policy primitives.
- [x] Loopback-only sanitized observability.
- [x] Public-safe OSS packaging rules and privacy canaries.

## Phase 2 — verified vertical slice

- [x] Typed adapters and append-only ChangeSet engine.
- [x] Same-session browser authority with exact target gates.
- [x] Standard, T123, narrow Zero, SEO, and page-specific HEAD contracts.
- [x] Separate publication controller, public verifier, and fixed page lifecycle.
- [x] Private isolated-lab round-trips and restart/rebind verification.

## Phase 3 — practical v1.0

- [x] Fourteen semantic MCP tools and one short-lived task-authority model.
- [x] Account-bound discovery, audits, safe Standard routing, T123 helpers,
  bounded Zero adapters, reference-page recipes, and hover-only controls.
- [x] Bounded copy-test learning contract with typed trace/replay/restore gates.
- [x] Sanitized public package, synthetic unit tests, read-only smoke, and
  documented Codex approval configuration.

## Next evidence gates

- [ ] Add more Standard families, Zero element families, and page settings only
  after separate reversible lab evidence.
- [ ] Research site-wide HEAD independently; never generalize from the
  page-specific route/runtime contract.
- [ ] Compare normal mode with Tilda Advanced Interface Mode and fail closed on
  inventory, pagination, sorting, or DOM-shape drift.
- [ ] Publish reproducible demos using synthetic or user-supplied lab data with
  explicit approval gates.
- [ ] Gather external users and contributors before making adoption claims.

## Explicitly out of scope

Production guarantees, universal Tilda coverage, arbitrary undocumented writes,
official editor-write API claims, assets/catalog/forms, cross-project moves,
trash recovery, site-wide HEAD, Advanced Mode compatibility, and automatic
publication.
